( How it goes )

My tried-and-true
design process

01 · Discover

Talk first

I interview users, read the data, and define "winning" as a number before any screen exists.

02 · Define

Scope to one slice

Cut the brief to the smallest work that proves the point, then name the metric it must move.

03 · Wireframe

Grey boxes first

Structure, copy and flow decisions happen here, where changing your mind costs nothing.

04 · Build

One track, not two

High-fidelity UI grows beside working code or a live model, so nobody designs what can't be built.

05 · Ship

Deploy and measure

Live fast, watch the metric, then remove whatever nobody used.
